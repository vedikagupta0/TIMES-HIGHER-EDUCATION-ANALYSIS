## 🎯 Overview

This project performs an in-depth statistical and visual analysis of universities ranked by Times Higher Education. The analysis aims to discover patterns, trends, and interesting facts about:

- University rankings across different metrics
- Regional distribution of top universities
- Performance indicators and their correlations
- Historical trends in university rankings
- Institutional characteristics of elite universities

## ✨ Features

- **Data Analysis**: Statistical analysis of university rankings and metrics
- **Visualizations**: Interactive and static charts to explore university data
- **Insights**: Key findings and trends about global higher education
- **Comparative Analysis**: Compare universities across different criteria
- **Regional Analysis**: Explore geographic distribution of top institutions

## 📊 Data Source

Data is sourced from the **Times Higher Education (THE) Rankings**, which is a global university ranking system that evaluates universities based on:

- Teaching quality
- Research output and citations
- International diversity
- Industry connections
- Financial sustainability

## 🚀 Installation

### Prerequisites

- Python 3.8+
- Jupyter Notebook
- pip or conda

### Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/vedikagupta0/TIMES-HIGHER-EDUCATION-ANALYSIS.git
   cd TIMES-HIGHER-EDUCATION-ANALYSIS
   ```

2. **Create a virtual environment**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

## 💻 Usage

### Running Jupyter Notebooks

```bash
jupyter notebook
```

Then navigate to the `notebooks/` directory and open any notebook to explore the analysis.

### Key Notebooks

- **exploratory_analysis.ipynb**: Initial data exploration and preprocessing
- **visualization.ipynb**: Visual representations of key metrics
- **insights.ipynb**: Deep-dive analysis and key findings

## 📈 Analysis

The analysis includes:

1. **Ranking Distributions**: How universities are distributed across ranking ranges
2. **Regional Patterns**: Geographic concentration of top universities
3. **Performance Metrics**: Correlation between different ranking factors
4. **Trend Analysis**: How rankings change over time
5. **Institutional Profiles**: Characteristics common among elite universities
